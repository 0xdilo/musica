# Security reports

Use [GitHub private vulnerability reporting](https://github.com/0xdilo/musica/security/advisories/new) to report a security issue without publishing it in an issue.

Do not attach credentials, browser cookies, service tokens, databases or recordings. Describe the affected version, setup and steps to reproduce with fictional data.

The application is designed for one trusted user alongside a local Navidrome instance. Keep the default loopback binding unless you have configured private-network access or an HTTPS reverse proxy.
